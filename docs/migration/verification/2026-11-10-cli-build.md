# CLI: build singola e multipersona

Data: 2026-11-10. Baseline Python: `fdad1d93e56496cc6cb9933b3089729175d5b5b3`.

La CLI collega `build-patient` e `build-all` al core, con scelta della
configurazione, modalità, OCR forzato e risultati testuali. L'avanzamento
dettagliato non è ancora esposto dal core: la CLI lo segnala prima della
build, salvo `--no-progress`. Gli altri comandi della baseline restano da
portare; la capability CLI rimane pending.

## Decisione G2

Il manutentore ha approvato l'applicazione di `--repo-root` ai controlli
privacy di entrambe le build: in assenza dell'opzione si usa la directory
corrente. Il controllo verifica i percorsi dei profili rispetto alla root
specificata e può rifiutare configurazioni accettate dalla baseline, che nei
runner esaminati accetta l'opzione senza applicarla. Una root errata non
garantisce la protezione dei percorsi. La build multipersona mantiene inoltre
il preflight già previsto dal core.

## Verifica

`cargo xtask check` è passato su Linux; i test CLI sintetici coprono build,
errori, cache, help e rifiuto privacy prima delle scritture. Non è una
qualifica completa della CLI né una prova su dati reali.
