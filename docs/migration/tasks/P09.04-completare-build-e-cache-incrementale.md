## Lavoro

Integrare pipeline per paziente e insieme, validazione iniziale, cache, build complete e report. Gestire esiti parziali e ripresa.

## Ambito e vincoli

La cache è derivata; non condividere output o cache scrivibili con il campione Python.

I file Rust precisi saranno identificati nel workspace introdotto da P03.
Limitare le modifiche ai moduli necessari e ai relativi test, documenti,
matrice di parità e ledger. Non ricostruire API da nomi ipotizzati.

## Verifiche e criterio di accettazione

Build completa/incrementale equivalenti; ripetizioni e modifiche dei sorgenti invalidano i dati appropriati.
