# P03.01 — Creare workspace e toolchain Rust

## Prerequisiti

[P00.03](P00.03-creare-e-pubblicare-sanikey-ng.md)

Stato di esecuzione: consultare [il ledger](../ledger.md).
Piano: [plan.md](../plan.md).

## Fonti da leggere

- `docs/architecture.md`.
- `CONTRIBUTING.md`.

## Lavoro

Creare sanikey-core, sanikey-cli e xtask; fissare toolchain e lockfile. Introdurre una CLI minima che riporti solo funzioni realmente disponibili.

## Ambito e vincoli

Nessun crate desktop prima di G1. Nessun comando non implementato può restituire successo come segnaposto.

I file Rust precisi saranno identificati nel workspace introdotto da P03.
Limitare le modifiche ai moduli necessari e ai relativi test, documenti,
matrice di parità e ledger. Non ricostruire API da nomi ipotizzati.

## Verifiche e criterio di accettazione

Build e test minimi riproducibili; directory e dipendenze rispettano l'architettura; primo esempio rustdoc eseguito.

## Chiusura

Seguire [CONTRIBUTING.md](../../../CONTRIBUTING.md) per controlli,
commit, evidenze e aggiornamento del ledger. Non dichiarare verifiche
su piattaforme o dispositivi non provati.
