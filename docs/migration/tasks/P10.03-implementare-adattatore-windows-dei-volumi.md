## Lavoro

Implementare controllo Windows di volume, filesystem, spazio e identità configurata secondo il contratto verificato.

## Ambito e vincoli

Non applicare euristiche dei mountpoint Linux alle lettere di unità.

I file Rust precisi saranno identificati nel workspace introdotto da P03.
Limitare le modifiche ai moduli necessari e ai relativi test, documenti,
matrice di parità e ledger. Non ricostruire API da nomi ipotizzati.

## Verifiche e criterio di accettazione

Test del sistema e delle differenze di identificazione verificati su Windows reale o VM idonea.
