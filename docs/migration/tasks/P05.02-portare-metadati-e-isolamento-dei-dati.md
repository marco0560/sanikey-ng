# P05.02 — Portare metadati e isolamento dei dati

## Prerequisiti

[P05.01](P05.01-portare-configurazione-e-validazione.md)

Stato di esecuzione: consultare [il ledger](../ledger.md).
Piano: [plan.md](../plan.md).

## Fonti da leggere

- `src/sanikey/metadata.py (baseline)`.
- `src/sanikey/models.py (baseline)`.
- `src/sanikey/privacy.py (baseline)`.

## Lavoro

Portare domini dei metadati, riferimenti e validazioni; proteggere originali e separazione dei pazienti. Separare le guardie di pubblicazione Git dalle invarianti del runtime installato.

## Ambito e vincoli

Nessuna dipendenza Git obbligatoria per l'utente finale.

I file Rust precisi saranno identificati nel workspace introdotto da P03.
Limitare le modifiche ai moduli necessari e ai relativi test, documenti,
matrice di parità e ledger. Non ricostruire API da nomi ipotizzati.

## Verifiche e criterio di accettazione

Metadati invalidi bloccano il lavoro prima dell'elaborazione; test d'isolamento e protezione dei dati superati.

## Chiusura

Seguire [CONTRIBUTING.md](../../../CONTRIBUTING.md) per controlli,
commit, evidenze e aggiornamento del ledger. Non dichiarare verifiche
su piattaforme o dispositivi non provati.
