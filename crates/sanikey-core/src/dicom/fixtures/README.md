istanza sintetica CT, con UID e paziente fittizi. Il record IMAGE punta a

l'istanza con gli stessi UID. SHA-256: `a6d1b1b47eb12c6729c45f94f8d39dbc8dea4fbce486999e476a5dadb77c1798`.
